# V2Ray 节点页四大功能实现方案

## Context

节点页刚完成工具栏重构 + 延迟/速度排序。用户选定再加 4 个功能：**① 定时测速+自动选最快节点、② 批量操作、③ 重复节点一键去重、④ 节点导出/备份**。探索确认：后端批量删除/测速接口已存在，测速台账存于 `v2ray_cfg` 表 `node_metrics` 键，`v2raymgr` 已有两个常驻 daemon 线程范式（stats/failover），分享链接生成/解析齐备（`node_to_share` / `parse_share_link`），**去重目前完全没有**，无任何导出端点。

## 一、定时测速 + 自动选最快（v2raymgr.py + 路由 + 前端弹窗）

**服务层 v2raymgr.py**（照抄 failover 线程范式）：
- settings 新键（`v2raydb.set_setting`，键值 JSON）：`speedtest_on`(默认 0)、`speedtest_interval`(分钟，默认 30，钳位 5~1440)、`speedtest_pick`(测完自动切换，默认 0)、`speedtest_dl`(对 ping 最快前 3 名加测下载，默认 0)、`speedtest_last`(最近一轮结果 {ts, tested, ok_count, best_name, best_ping, switched})。
- `_speedtest_cfg()` 读取；`set_speedtest(on, interval, pick, dl)` 校验落库 + `ensure_speedtest_thread()`。
- `ensure_speedtest_thread()`：幂等 daemon 线程 `v2ray-speedtest`，循环 `Event.wait(20)` 唤醒检查；`_RUN_NOW` 标志或（on 且距上次运行 ≥ interval）则执行 `_speedtest_round(cfg)`。
- `_speedtest_round()`：`list_nodes()` 全量 → `ThreadPoolExecutor(8)` 并发 `real_ping()`（复用现有临时内核探测，返回 ms）→ 结果经新增通用 `_metric_set(nid, **kv)`（带模块内锁）写 `node_metrics`；`speedtest_dl` 开时对 ping 最快前 3 用 `real_dl()` 加测并写 `dl` 字段；`speedtest_pick` 开时自动切换：当前节点 ping 失败 → 立即切；否则最快节点 ping < 当前 × 0.8 才切（防抖动），切换用 `start(nid, auto_probe=False)` 且先 `acquire(blocking=False)` `_FAILOVER_BUSY`（与看门狗互斥）；过程写 `_conn_log("speedtest", …)`。
- `_probe_after_switch` 之后的连接日志 kind 新增 `"speedtest"`。

**路由 app/routes/ide/v2ray.py**：
- `POST /api/v2ray/speedtest/config` {on,interval,pick,dl} → `v2raymgr.set_speedtest`。
- `POST /api/v2ray/speedtest/run` → 置 `_RUN_NOW` 立即测一轮（异步）。
- `GET /api/v2ray/status`（L73）响应里追加 `speedtest` 字段（cfg + last + running），前端无需新 GET。

**app/__init__.py**：`_init_v2ray_traffic()` 里加一行 `v2raymgr.ensure_speedtest_thread()`（服务启动即拉起，关闭状态时空转）。

**前端 47 JS**：ntool 操作组新增「优选」按钮（`V2.speedtest.on` 时加 `on` 态高亮）→ 点击弹自绘 modal（复刻 `v2NodeEditModal` 的 `.v2v-modal-ov` 模式）：开关、间隔分钟、自动切换最快、同时测下载四个控件 + 最近一次结果展示 + [保存][立即测一轮]。`CONN_KIND_TXT`（L2392 附近）加 `"speedtest": "优选"`。

## 二、批量操作（前端为主 + 1 个新端点）

- 节点卡片 `.v2v-ico` 前加勾选块 `<span class="v2v-ck" data-act="node-check" data-id>`（自绘样式，CSS 已有可参考的 `.v2v-check` 但未使用；不用原生 input 避免双触发）。选中态存 `V2.sel`（数组）。
- `V2.sel` 非空时在工具行下渲染 `.v2v-batchbar`：`已选 N` + [全选当前列表] [批量测速] [批量测下载] [移动分组] [删除] [取消选择]。
  - 批量测速/测下载：完全复用 ping-all（case 3052）/ dl-all（case 3022）的分批 worker 流程，仅 ids 换成选中集合（测下载仍只测 ping 可用者）。
  - 批量删除：`post("/api/v2ray/nodes/delete", {ids})`（已有，天然支持批量）。
  - 移动分组：新端点 **`POST /api/v2ray/nodes/batch-grp` {ids, grp}** → 循环 `v2raydb.update_node(nid, grp=grp)`（grp 可为空串=移出分组）；前端 `uiPrompt` 输入或从 `V2.groups` 现有分组选择（uiModal 里列出 + 新建输入）。
- `v2NodeFilteredList()` 结果作为「全选当前列表」的范围；过滤/tab 切换后自动清空不在列表中的选中项。

## 三、重复节点一键去重（路由 + 前端按钮）

- **后端 `POST /api/v2ray/nodes/dedupe` {apply: bool}**：`list_nodes()` 按 **`(proto, server, port, uuid|password[, method])`** 归组（uuid 在 node_json：vmess/vless 取 `uuid`，trojan/ss 取 `password`，ss 另拼 `method`）；组内保留策略：已连接节点（active_node setting）优先，否则 `created_at` 最早者；其余 `v2raydb.delete_nodes(ids)` **软删除**（进回收站可恢复）。dry-run 返回 `{dup_groups, remove_ids, remove_names, keep_names}`，apply 后返回实际删除数。
- **前端**：表头右侧「回收站」旁加「去重」按钮 → 先 dry-run，`uiConfirm` 展示「发现 N 组重复，将移除 M 个（进回收站）」→ 确认后 apply → `v2TrashFetch() + v2Reload()`。

## 四、节点导出/备份（1 个新端点 + 前端下载）

- **后端 `POST /api/v2ray/nodes/export` {ids?: [], format: "txt"|"json"}**：
  - ids 省略 = 全部节点；txt：逐节点 `v2raycfg.node_to_share(node)`（raw 优先，L1109）拼多行文本；json：`{version, exported_at, nodes:[{link, name, remark, grp, proto, server, port}]}`。
  - 响应照 downloads.py CSV 模式（L593-614）：`Response(attachment, mimetype=text/plain|application/json)` + `Content-Disposition` 双写法（ASCII 回退名 + `filename*=UTF-8''` 中文名 `v2ray_nodes_YYYYmmdd_HHMM.txt`）。
  - 导入无需新端点：JSON 备份里的 link 逐行走现有 `/api/v2ray/nodes/add` 的 links 通路（grp/remark 附加到 add 后的可选 fields——在 `/nodes/add` 端点为每个 link 支持可选 `grp` 映射，改动很小；不做则 JSON 与 txt 等价，仅多 grp 信息）。**决定**：txt 链接导出 + JSON 备份（含 grp/remark），导入端 `/nodes/add` 的 links 支持 `[{link, grp, remark}]` 对象数组形式（向后兼容纯字符串）。
- **前端**：表头「导入节点」旁加「导出」按钮 → 弹小 modal 二选一（导出链接 txt / 导出备份 json）；范围 = 有选中集合用选中，否则当前过滤列表；`fetch` POST → `res.blob()` → 复刻 52 JS 的 `dlSaveBlob` 模式（objectURL + 隐藏 `<a download>`，在 47 JS 内联实现）。

## UI 布局分配（避免再次拥挤）

- 表头右侧：`[导入节点 primary] [导出] …spacer… [去重] [回收站]`
- ntool 操作组：`[优选(on态)] [全部测速] [测下载] [删除超时]`
- 批量条：仅选中 >0 时出现在工具行与 tab 行之间

## 验证

1. **后端**：项目 venv `python -m py_compile` 三个 .py；用 venv python 离线 import `v2raydb` 对去重键函数做只读 dry-run 验证（不写库）。
2. **前端**：括号配平检查 + 静态预览页（真实 CSS + 标记副本）目检勾选框、批量条、优选按钮三态（深色 + 浅色 + 窄屏）。
3. **联调**：模板自动重载但 **.py 改动需重启服务**（服务以 root 运行，需用户授权重启）；重启后由用户在浏览器验证：优选开关保存 → 立即测一轮 → 连接日志出现「优选」事件；勾选批量删除/移动分组；去重进回收站；导出 txt/json 文件下载并回导入。
