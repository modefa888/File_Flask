PLUGIN · index.html + style.css

绚烂插件面板

这是通过宿主以 iframe 加载的插件富页面，由 index.html + style.css 渲染。

🚀

调用宿主通知

通过 window.parent.IDE.notifications.show 弹提示。

🗂️

编辑区标签页渲染本页

调用 IDE.editors.open({ index })，把本页以富页面渲染进右侧编辑区。

⚡

执行命令

通过 IDE.executeCommand 触发已注册命令。

🌿

编辑区打开「另一页面」

用 editors.open({ index: "view.html" }) 在右侧渲染与左边不同的 HTML。
